📄 Informe corregido para presentar a VIVA

Es el informe de gestión original con las siguientes correcciones:
— Se eliminan las filas que NO cumplen la condición (gestión posterior al pago).
— Se dejan todas las filas que SÍ cumplen la condición.
— Se crean filas nuevas para los códigos "Sin gestión" y "Gestión posterior", con la fecha del pago y los datos requeridos.
— El resultado: exactamente 1 fila por código que cumple la condición.

✔ Filas que cumplen condición → se conservan ⚡ Gestión posterior → se crea fila nueva con fecha de pago ✚ Sin gestión → se crea fila nueva completa
